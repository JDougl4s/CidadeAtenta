# 🏙️ Cidade Atenta - Sistema de Denúncia Comunitária

O **Cidade Atenta** é uma aplicação web desenvolvida como solução para um Mini Hackathon académico (Faculdade INBEC). O desafio exigia a ideação, prototipação e desenvolvimento de um MVP funcional num tempo limite de **apenas 2 horas**.

##  O Desafio
**Problema:** Moradores precisam de denunciar problemas urbanos (buracos na via, lixo irregular, falta de iluminação, etc.), mas enfrentam barreiras burocráticas ou não sabem a quem recorrer.
**Solução:** Criar uma plataforma web simples, intuitiva e acessível para o registo e acompanhamento destas ocorrências.

##  Funcionalidades Desenvolvidas
Com forte foco em **UX/UI e usabilidade**, o sistema conta com:
* **Formulário Ágil:** Seleção do tipo de ocorrência por abas/categorias e campos de localização detalhada (rua, bairro, ponto de referência).
* **Upload de Mídia:** Suporte para envio de imagens ou vídeos do problema.
* **Privacidade:** Opção de denúncia identificada (com e-mail/telefone) ou 100% anônima.
* **Acompanhamento de Status:** As ocorrências são salvas com um status dinâmico (`Pendente`, `Em atendimento`, `Resolvido`), visível para o utilizador (apenas leitura após o envio).
* **Acessibilidade:** Interface estruturada considerando opções básicas de acessibilidade para pessoas com deficiência.

##  Tecnologias e Prototipação Rápida
Devido ao âmbito e ao tempo crítico de 2 horas para a entrega final, atuei na orquestração de Inteligência Artificial (Engenharia de Prompts) para gerar rapidamente o código funcional da interface.
* **Stack:** HTML5, CSS3 e JavaScript.
